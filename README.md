# tvbox-source

个人 TVBox 接口源仓库，仅供学习使用。

## 接口地址

**主配置：**
```
https://raw.githubusercontent.com/wrt666666/tvbox-source/main/config.json
```

**多仓聚合：**
```
https://raw.githubusercontent.com/wrt666666/tvbox-source/main/multi.json
```

## 使用方法

在 TVBox 中：设置 → 配置 → 添加接口 → 粘贴上面的 raw 链接 → 保存 → 刷新。

## 更新

- 上游接口源不稳定，可能随时失效
- 修改 JSON → push → TVBox 刷新即可
